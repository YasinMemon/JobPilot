# Claude Instructions for JobPilot

## Project Overview
JobPilot is a modern job tracking platform built with Next.js, MongoDB, Better-Auth, and AI (Groq SDK). It parses job applications from Gmail and offers AI assistance.

## Instruction Priority
**Primary source of truth:** `AGENTS.md`

## Development Workflow
1. Read `AGENTS.md` first.
2. Read docs in `docs/` directory.
3. Understand existing architecture in `models/` and `services/` before modifying.
4. Keep TypeScript strict.
5. Use existing UI components.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
