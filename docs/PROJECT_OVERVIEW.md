# JobPilot Project Overview

## Product Purpose
JobPilot is an intelligent job application management platform designed to automate the tracking of job applications by integrating with users' emails and providing AI-powered career insights.

## Target Users
Job seekers, professionals, and students managing multiple job applications who want an organized, automated way to track progress.

## Major Features
- **Email Parsing:** Integration with Gmail to fetch and extract job application data.
- **Application Tracking:** Dashboard to track status, company, and dates.
- **AI Career Assistant:** Chat and AI features to help with resumes, skill gaps, and interview prep.
- **Profile Management:** Robust user profiles with resumes and attachments.

## Technology Stack
- **Frontend:** Next.js (App Router), React, Tailwind CSS, Ant Design
- **Backend:** Next.js Route Handlers, Node.js
- **Database:** MongoDB, Mongoose
- **Auth:** Better-Auth
- **AI/LLM:** Groq SDK
- **Integrations:** Google APIs (Gmail), Cloudinary
