# AI Features

## AI Integrations
JobPilot uses the **Groq SDK** for fast LLM inference.

### Core Workflows
- **Resume parsing / generation:** Extracting text and structuring data.
- **Application summarization:** Summarizing job emails and extracting company/role.
- **Career Assistant:** Chatting with users about interview prep and skill gaps.

### AI Development Rules
- Prefer structured outputs where appropriate.
- Validate AI-generated data before storing it.
- Never trust AI output blindly.
- Handle model failures gracefully.
- Do not send unnecessary personal information to AI providers.
